# Product vision

## One line

A personal space where your notes, tasks, time, plans, and everything that inspires you live
together — calm enough to live in every day.

## The problem

People who make things juggle five or six tools: a notes app, a task manager, a calendar, a
timer, bookmarks, a screenshot folder, a Figma page of "inspo". Each is fine alone; together
they fragment attention and nothing connects. A task can't point at the reference that
inspired it; the week's plan can't see where time actually went.

## The idea: one space, seven rooms

The product is a single **space** with **rooms**. Each room is a focused tool, and every item
can link to items in other rooms.

| Room        | Job                                                                         |
| ----------- | --------------------------------------------------------------------------- |
| **Today**   | The front door: what's due, what's scheduled, focus time — one calm view    |
| **Tasks**   | Capture fast, organize lightly, finish with satisfaction                    |
| **Orbit**   | Run a project as a board: stages, a brief, a target date, and its health    |
| **Planner** | Shape the week: drag tasks onto days, block time                            |
| **Notes**   | Notion-style pages with a block editor                                      |
| **Time**    | Focus sessions and time tracking that feed the planner                      |
| **Vault**   | The backup bucket: save websites, designs, components, images, files, ideas |

## Principles

1. **Calm by default.** Nothing blinks for attention. Color is earned, not sprinkled.
2. **Satisfying to use.** Every frequent interaction (completing, saving, moving) has
   considered, expressive motion. Small rewards build the habit.
3. **Capture in under two seconds.** Anything — a task, a link, a thought — goes in from
   anywhere with one shortcut.
4. **Everything connects.** Links between rooms are first-class, not an afterthought.
5. **Keyboard-first, mouse-friendly.** Power users never need the mouse; nobody is forced
   to learn shortcuts.
6. **Yours.** Private by default, exportable, no lock-in.

## Audience (MVP)

Public multi-user product. Each user signs up and gets a private personal space. Primary
persona: designers, developers, and makers who collect inspiration and run their own work.

## Out of scope for MVP

Real-time collaboration, shared spaces, mobile native apps, third-party calendar sync,
AI features. The data model leaves room for shared spaces later (see data-model.md).
